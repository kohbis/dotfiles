# Global Rules

## Working directory

- Do not use `/tmp` as a working directory.
- Always create a `tmp/` directory under the current working directory instead.

## Scope

- Deliver what was asked, at the scope intended. Make routine judgment calls yourself; check in only when different readings of the request would lead to materially different work.
- If the request looks mistaken or a better approach exists, say so in a sentence and continue as asked — don't quietly narrow, widen, or transform it.
- Finish the whole task. If part of it is blocked, complete the rest and say plainly what was left out and why.

## Length

- Match length to what the task needs, in replies and in files you write alike. Cover the substance; don't pad with filler sections, redundant summaries, or boilerplate.
- Lead with the outcome, then supporting detail for readers who want it.

## Verification

- Verify with checks that produce evidence — run the test, reproduce the case, read the call site. Don't repeat a check that already passed.
